JSF FASHION WEAR — WEBSITE ZIP

ফাইল চালানোর নিয়ম:
1. ZIP ফাইল Extract করুন।
2. index.html ফাইলটি Chrome-এ খুলুন।
3. ওয়েবসাইটের ডিজাইন ও Add to Bag কার্ট পরীক্ষা করুন।

GitHub Pages-এ প্রকাশ:
1. GitHub-এ নতুন repository তৈরি করুন।
2. এই ZIP-এর ভেতরের সব ফাইল repository-তে Upload করুন।
3. Settings > Pages > Deploy from a branch নির্বাচন করুন।
4. Branch: main এবং folder: / (root) দিয়ে Save করুন।
